# 🩺 Sepsis Risk Prediction — EDA & Machine Learning

Early prediction of **sepsis** in ICU patients using hourly clinical vitals and lab measurements. This project covers the full pipeline — exploratory data analysis, preprocessing, model training/evaluation, and a **Flask web app** that gives clinicians a real-time sepsis risk score from patient data.

> ⚠️ **Disclaimer:** This project is for educational/research purposes only. It is **not** a certified medical device and must not be used for real clinical decision-making.

---

## 📌 Project Overview

Sepsis is a life-threatening condition caused by the body's extreme response to infection, and early detection significantly improves patient outcomes. This project uses hourly ICU time-series data (vitals, labs, and demographics) to predict the likelihood of sepsis onset.

**Key highlights:**
- 📊 In-depth Exploratory Data Analysis (EDA) on **1.55M+ hourly ICU records** from **40,336 patients**
- 🧹 A clinically-aware preprocessing pipeline (patient-wise forward-fill, median imputation, scaling)
- 🤖 Two ML models trained and compared: **Logistic Regression** and **Random Forest**
- 🏆 Best model auto-selected by **PR-AUC** (the appropriate metric for this highly imbalanced problem) and exported as a deployable pickle bundle
- 🌐 A **Flask web application** with a clinician-friendly form for real-time risk scoring

## 📊 Dataset

The dataset contains **hourly ICU patient records** with vitals, laboratory values, and demographic information, along with a binary `SepsisLabel`.

| Property | Value |
|---|---|
| Total records | 1,552,210 hourly rows |
| Unique patients | 40,336 |
| Average records per patient | ~38.5 hours |
| Sepsis-positive rows | ~1.8% (highly imbalanced) |
| Patients with ≥1 sepsis-positive hour | ~7.27% |
| Feature columns | Vitals (HR, O2Sat, Temp, SBP, MAP, DBP, Resp…), Labs (BUN, Creatinine, Glucose, Lactate, WBC, Platelets…), Demographics (Age, Gender, ICU unit, ICU length-of-stay) |

Many lab values are sparse (drawn only when clinically indicated) — e.g. `Bilirubin_direct` and `Fibrinogen` are missing in >99% of rows, which directly informed the preprocessing strategy.

> Place the raw file as `Dataset.csv` in the project root before running the notebook. (Not included in this repository due to size/licensing — see the dataset source you used, e.g. PhysioNet/Kaggle Sepsis Prediction dataset.)

## 🔬 Methodology

1. **Data Loading & Overview** — shape, dtypes, patient counts
2. **Missing Value Analysis** — column-wise missingness, visualized
3. **Target Variable Analysis** — class imbalance at row- and patient-level
4. **Demographics** — age/gender distribution vs. sepsis outcome
5. **Vital Signs Analysis** — sepsis vs. non-sepsis comparison for HR, O2Sat, Temp, MAP, Resp
6. **Correlation Analysis** — heatmap of key clinical variables
7. **Temporal Pattern Analysis** — sepsis rate across ICU length-of-stay buckets
8. **Preprocessing** — patient-wise forward-fill, dropping columns >90% missing, median imputation, standard scaling
9. **Modeling** — grouped train/test split (by patient, 80/20) to avoid patient leakage
10. **Evaluation** — classification report, ROC-AUC, PR-AUC, confusion matrices
11. **Deployment** — best model (by PR-AUC) bundled with its preprocessing into `sepsis_model.pkl`

---

## 🏆 Model Performance

Because sepsis-positive rows are rare (~1.8%), **PR-AUC (Average Precision)** — not ROC-AUC — is the primary metric used for model selection.

| Model | ROC-AUC | PR-AUC |
|---|---|---|
| **Random Forest** ✅ (selected for deployment) | 0.8213 | **0.0862** |
| Logistic Regression | 0.7430 | 0.0673 |

*Random Forest was selected as the best-performing model based on PR-AUC and exported for deployment.*

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/sepsis-prediction.git
cd sepsis-prediction
```

### 2. Create a virtual environment (recommended)
```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```
Additional packages needed to run the notebook (EDA/training):
```bash
pip install jupyter matplotlib seaborn
```

### 4. Run the notebook (EDA + training + export)
Add `Dataset.csv` to the project root, then run all cells in:
```
Sepsis_Prediction_EDA_ML.ipynb
```
This produces `sepsis_model.pkl`, which the Flask app loads at startup.

### 5. Launch the web app
```bash
python app.py
```
Open **http://127.0.0.1:5000** in your browser to use the sepsis risk prediction form.

## 🌐 Using the App

- Fill in a patient's current vitals, labs, and demographics (any blank field defaults to the training-set median).
- Submit the form to get a **real-time sepsis risk probability** and risk tier: **Low / Moderate / High / Critical**.
- A JSON API endpoint is also available for programmatic use:

```bash
curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"HR": 110, "O2Sat": 92, "Temp": 38.5, "Age": 65}'
```
